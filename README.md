# 🍽️ AI Restaurant Intelligence Platform

An AI-powered restaurant analytics and recommendation platform built using Streamlit, NLP, Recommendation Systems, Geo Analytics, and Live Google Places API integration.

---

# 🚀 Live Demo

🔗 https://restaurant-rating.streamlit.app/

---
# Dataset
For the Dataset please visit the yelp website and download the raw dataset 
You can download the dataset from the given link https://business.yelp.com/data/resources/open-dataset/?utm_source=chatgpt.com

# 📌 Features

## 📊 Executive Analytics Dashboard
- Restaurant performance analytics
- Dynamic KPI metrics
- Cuisine trend analysis
- Customer engagement insights
- Interactive Plotly visualizations

---

## 🤖 AI Dining Discovery
- Smart restaurant recommendations
- Similar restaurant finder
- Recommendation engine using TF-IDF + Cosine Similarity
- Premium restaurant cards with AI insights

---

## 😊 Customer Sentiment Intelligence
- NLP-powered sentiment analysis
- Positive vs negative review intelligence
- Interactive sentiment visualizations
- WordCloud analysis
- Customer behavior insights

---

## 🌍 Geo Intelligence Dashboard
- Interactive restaurant maps
- Cuisine hotspot analytics
- Geo-based restaurant intelligence
- Clustered location visualization
- Heatmap-ready architecture

---

## 🤖 AI Restaurant Advisor
- Live restaurant discovery using Google Places API
- Dynamic location-based recommendations
- Real-time cuisine intelligence
- AI-generated dining insights
- Works even outside the local dataset

---
